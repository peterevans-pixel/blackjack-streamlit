## App Description
For my project, I plan to create a Blackjack game using Python and Streamlit. The app will allow users to play Blackjack against a computer dealer. The goal is to get as close to 21 as possible without going over. I want to make the game simple to use and interactive so that users can enjoy playing Blackjack directly through the website.

## Intended Users
This app is intended for anyone who enjoys card games or wants to learn how to play Blackjack. It will be designed for beginners as well as people who already know how to play.

## Planned Features
- Allow players to hit or stand during each round.
- Have a computer dealer that automatically plays against the user.
- Calculate the value of each hand and determine the winner.
- Keep track of wins and losses.
- Allow users to start a new round.
